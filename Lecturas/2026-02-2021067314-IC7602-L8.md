# L8 - ICMP (Internet Control Message Protocol)

**1. ¿Cómo funciona ICMP?**
ICMP es un protocolo que se usa para que los dispositivos de una red se avisen entre sí cuando algo sale mal, o para comprobar si un equipo está disponible. No sirve para enviar datos normales como páginas web o archivos, sino solo mensajes de control y de error.
Funciona así: cuando un router o un dispositivo recibe un paquete que no puede entregar por ejemplo, porque el destino no existe, la red está muy congestionada, o el paquete tardó demasiado en llegar, en lugar de simplemente descartarlo en silencio, genera un mensaje ICMP y se lo envía de vuelta al equipo que originalmente mandó el paquete. Así, quien envió la información se entera de qué pasó y por qué no llegó su mensaje.
También se usa para hacer preguntas simples entre equipos, como preguntar si está ahí, y esperar una respuesta que confirme que el otro equipo sigue activo y accesible.

**2. Aplicaciones de ICMP en las comunicaciones**

- **Ping:** es la aplicación más conocida de ICMP. Sirve para comprobar si un dispositivo está disponible en la red, enviándole un mensaje y esperando su respuesta. Si responde, significa que hay conexión; si no responde, algo está fallando.
- **Traceroute:** utiliza mensajes ICMP para mostrar el camino (los routers) por los que pasa un paquete desde el origen hasta el destino, ayudando a identificar en qué punto de la red se está perdiendo o retrasando la información.
- **Reporte de errores:** avisa cuando un paquete no pudo llegar a su destino, cuando la red está congestionada, cuando el tiempo de vida del paquete (TTL) se agotó, o cuando hay algún problema con la ruta que debía seguir.
- **Redirección de rutas:** un router puede usar ICMP para avisarle a un dispositivo que existe un camino más corto o más eficiente para llegar a cierto destino.
- **Diagnóstico de redes:** en general, administradores de redes usan herramientas basadas en ICMP para detectar fallas, medir tiempos de respuesta y verificar la conectividad entre equipos, lo que lo hace muy útil para el mantenimiento y solución de problemas en una red.
