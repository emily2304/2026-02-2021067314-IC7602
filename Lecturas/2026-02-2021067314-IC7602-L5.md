# L5 — Port-Based Authentication (802.1X)

**1. ¿Cómo funciona el Port-Based Authentication?**

Es un sistema de seguridad que bloquea un puerto de red (por ejemplo, en un switch o en un punto de acceso WiFi) hasta que el dispositivo que se quiere conectar demuestre quién es. Mientras no se identifique, el puerto solo deja pasar los mensajes necesarios para hacer la autenticación, nada más. Una vez que el usuario o equipo comprueba su identidad (con usuario y contraseña, certificado, etc.), el puerto se "abre" y ya puede usar la red con normalidad. Si la autenticación falla, el puerto se mantiene cerrado.

**2. Componentes principales de 802.1X**

- **Supplicant (el que pide acceso):** es el dispositivo o programa del usuario que quiere conectarse a la red, por ejemplo una laptop o un celular.
- **Authenticator (el que controla el acceso):** es el equipo de red que actúa como "guardia", como un switch o un punto de acceso WiFi. Es quien mantiene el puerto cerrado o abierto según el resultado de la autenticación.
- **Authentication Server (el que verifica la identidad):** normalmente un servidor RADIUS, que es quien realmente revisa las credenciales (usuario, contraseña, certificado) y le dice al Authenticator si debe dejar entrar o no al dispositivo.


**3. ¿Por qué es relevante este tipo de autenticación?**

Porque evita que cualquier persona pueda conectarse a la red simplemente enchufando un cable o acercándose a una red WiFi. Sin este control, alguien externo podría conectarse a un puerto libre y tener acceso a la red interna sin ningún permiso. Con 802.1X, cada dispositivo debe comprobar su identidad antes de poder usar la red, lo que ayuda a mantener fuera a usuarios o equipos no autorizados y hace la red mucho más segura, tanto en oficinas como en redes inalámbricas públicas.
