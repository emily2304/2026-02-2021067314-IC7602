## Clasificación de las arquitecturas de red

**1\. Diferencia entre WAN y MAN**

Una MAN es una red del tamaño de una ciudad menos de 100 km, como las redes de cable o internet inalámbrico de alta velocidad. Una WAN es mucho más grande porque cubre países o continentes enteros y conecta millones de dispositivos. Internet es el ejemplo más grande de WAN. 
Entonces la MAN es local como una ciudad como Cartago y la WAN es global como la red de Rusia. 

**2\. Diferencia entre red orientada a conexión y no orientada a conexión**

En una red **orientada a conexión** como el teléfono, antes de comunicarse se crea un camino fijo entre los dos que se van a comunicar, y ese camino queda reservado solo para ellos mientras dura la llamada. Es confiable porque nadie más usa esa línea, pero desperdicia recursos si no se está hablando todo el tiempo.

En una red **no orientada a conexión** como Internet, no se reserva ningún camino fijo, los datos se envían cuando hay espacio disponible, compartiendo el mismo enlace con otros usuarios. Es más eficiente, pero no garantiza la misma calidad constante.

**3\. ¿Qué es una red punto a punto?**

Es una red donde dos dispositivos se comunican directamente entre sí y se puede armar de dos formas:

* **Con circuito dedicado** como el teléfono: primero se conecta la llamada, luego se envían los datos, y al final se corta la conexión. Mientras dura esa red, esa línea es solo para esos dos únicos usuarios.
* **Sin circuito dedicado** por paquetes: los datos se envían en el momento que hay disponibilidad en el enlace, sin reservar nada antes.

**4\. FDM y TDM**

Son dos formas de repartir un mismo cable o enlace entre varias conexiones.

* **FDM:** se reparte el enlace por **frecuencias**. Cada conexión tiene su propia banda como canales de radio distintos y puede usarla todo el tiempo.
* **TDM:** se reparte el enlace por **tiempo**. Cada conexión usa todo el ancho del enlace, pero solo durante turnos cortos que se repiten, como si varias personas se turnaran para hablar por el mismo teléfono.
